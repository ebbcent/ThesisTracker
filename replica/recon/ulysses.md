## 3. Écrans / fonctions pertinents

| ID | Écran / fonction | Description (nos mots) | Source |
|---|---|---|---|
| S01 | Réglage d'objectif | Type : environ / au moins / au plus ; métrique : caractères avec ou sans espaces, mots, phrases, paragraphes, lignes, pages, temps de lecture ; rattaché à une feuille, un groupe ou un projet. | #2, #3, #7 |
| S02 | Objectif à échéance | Date limite ajoutée à un objectif ; l'app calcule la quantité restante par jour ; nombre de jours d'écriture restants affiché sous la progression ; jours de la semaine jamais travaillés exclus ; option compter ou non le jour J. | #4, #13 |
| S03 | Objectif « chaque jour » de groupe/projet | Somme de ce qui est écrit dans toutes les feuilles du groupe ; remise à zéro à minuit. | #2, #6 |
| S04 | Historique de groupe | Visualisation des quantités quotidiennes (aujourd'hui + 10 jours), meilleur jour, moyenne quotidienne, export CSV de tous les jours enregistrés. | #5 |
| S05 | Indicateur de progression | Petit cercle de progression à côté de chaque feuille dans la liste et dans la feuille. | #3 |
| S06 | Tableau de bord / statistiques | Compteurs (mots, caractères, paragraphes, pages norme, temps de lecture) pour la feuille et la sélection ; page norme réglable (60 car. × 30 lignes par défaut). | #7, #8 |
| S07 | Projets | Mode qui ne montre que le projet en cours dans la barre latérale ; objectif + échéance mis en avant ; contenu séparé du matériel de recherche. Pensé pour livre/thèse. | #16, #19 |
| S08 | Feuilles « matériel » | Notes/recherche rattachées à un groupe, exclues des statistiques et de l'export du groupe. | #10 |
| S09 | Filtres et mots-clés | Groupes intelligents par critères (mot-clé, date…), filtres « 7 derniers jours » et favoris. | #12, #15, #17 |
| S10 | Sauvegardes automatiques | Mac : horaires sur 12 h, quotidiennes sur 7 j, hebdomadaires sur 6 mois ; locales, non synchronisées ; parcours et restauration sélective. | #9 |
| S11 | Synchro iCloud | Incluse ; l'app ne peut pas forcer la synchro ; problèmes ponctuels résolus par déconnexion/reconnexion iCloud. | #21, #22 |

## 6. À ne pas reprendre (skip)

| Élément | Raison |
|---|---|
| Éditeur Markdown, export publication, blocs de code | éditeur complet, hors périmètre |
| Synchro iCloud de la bibliothèque de texte | Writing Process a déjà sa synchro/fusion deux Mac ; pas de texte stocké |
| Publication web (WordPress, Ghost, etc.) | compte en ligne / serveur |
| Relecture IA / outils de style en ligne | IA / service externe |
| Abonnement, Setapp | modèle économique hors sujet |
| Icônes, noms, libellés de l'app | marque / textes protégés |
