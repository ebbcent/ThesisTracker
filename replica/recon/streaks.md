## 5. À ne pas reprendre (skip)

| Élément | Raison |
|---|---|
| Lecture des données Santé (pas, anneaux, entraînements) | Non pertinent pour l'écriture et HealthKit indisponible sous macOS de façon utile ; dépendance de plateforme |
| Appli Apple Watch, complications | Hors périmètre (app macOS) |
| Partage de tâches avec d'autres utilisateurs | Exige serveur/compte |
| Interface en tuiles, icônes, nom « Streaks », bibliothèque d'icônes | Clean room (marque et visuels) |
| Écriture d'« État d'esprit » dans Santé | API iOS ; Writing Process a déjà humeur/énergie en interne |
