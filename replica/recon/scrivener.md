## 3. Écrans / fonctions pertinents

| ID | Écran / fonction | Description (nos mots) | Source |
|---|---|---|---|
| S01 | Fenêtre « Cibles du projet » | Deux jauges : cible du manuscrit (total) et cible de la session (jour). Réglage par clic sur le chiffre. | #3, #10 |
| S02 | Options de la cible de session | Calcul automatique depuis une date limite ; cases des jours de la semaine où l'on écrit ; option « écrire le jour de l'échéance » ; heure/mode de réinitialisation (ex. minuit) ; compter le texte écrit hors du manuscrit ou non ; ne compter que les documents inclus dans la compilation ; autoriser les valeurs négatives (suppressions) ; notifications à l'atteinte. Recalcul quotidien si on a manqué un jour ou dépassé. | #3, #10, #17, #19, #23 |
| S03 | Cible par document | Icône cible dans le pied de l'éditeur ; quantité en mots ou caractères ; option d'afficher le dépassement ; en vue groupée, somme des sous-documents. | #20, #10 |
| S04 | Vue plan (outliner) | Colonnes statut, label, cible et progression pour chaque section. | Sources tutoriel binder (https://app.indieauthormagazine.com/?p=2885) |
| S05 | Historique d'écriture | Tableau par jour : mots ajoutés dans le manuscrit, hors manuscrit, total (net des suppressions) ; moyennes ; nombre de jours d'écriture ; export CSV. | #4, #5, #14 |
| S06 | Statistiques du projet | Comptes du manuscrit / de la sélection ; pages estimées « imprimées » et « format poche » ; fréquence des mots. | #7, #24 |
| S07 | Instantanés (par document) | Prise manuelle (un ou plusieurs documents), titrage, comparaison avec niveaux de granularité (ajouts soulignés, suppressions barrées), retour arrière. Copie du texte seulement, pas des métadonnées. | #9, #12, #13 |
| S08 | Classeur + statuts/labels | Arborescence chapitres/sections ; statut (« à faire », « 1er jet », etc.) et label couleur visibles dans classeur, tableau de liège et plan. | #6 |
| S09 | Mode composition | Plein écran, page sur fond assombri réglable, barre de contrôle cachée, défilement « machine à écrire ». | #8 |

## 6. À ne pas reprendre (skip)

| Élément | Raison |
|---|---|
| Éditeur de texte riche, mode composition, défilement machine à écrire | exige un éditeur complet ; Writing Process saisit des totaux, n'héberge pas le texte |
| Comparaison textuelle d'instantanés, retour arrière du texte | nécessite le texte du chapitre |
| Fréquence des mots | nécessite le texte |
| Compilation / mise en page / notes de bas de page | hors périmètre (traitement de texte) |
| Synchro Dropbox | dépendance externe + compte en ligne ; on reste sur iCloud |
| Outils d'écriture Apple Intelligence | IA, hors périmètre |
| Libellés, icônes, noms (« Scrivenings », etc.) | marque / textes protégés |
